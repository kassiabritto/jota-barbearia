# Jota Barbearia — site

Site estático (HTML, CSS e JS), sem build.

## Publicar no GitHub Pages
1. Envie todo o conteúdo desta pasta para a raiz do repositório (index.html na raiz).
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. O site abre em https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

## Onde editar
- Preços, horários e links: ficam direto nos arquivos .html (procure "Consulte").
- Link de avaliação do Google: ainda não incluído (botão aparece quando o link for informado).
